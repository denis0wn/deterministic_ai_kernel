# Студийный парк оборудования (фото/видео)

Основная камера студии — Sony A7 IV, серийный номер CAM-A7IV-0001.
Резервная камера — Sony A7C II, серийный номер CAM-A7C2-0002.

Объективы:
- Sony FE 35mm f/1.4 GM — штатный репортажный.
- Sony FE 24-70mm f/2.8 GM II — универсальный зум.

Видеозапись:
- Внешний рекордер Atomos Ninja V.
- Для 4K25 используется кодек XAVC S-I с потоком 100 Мбит/с.
- Для 1080p50 используется XAVC S 50 Мбит/с.

Политика съёмки:
- Максимальный ISO для видео — 3200 (выше — только с разрешения оператора).
- Баланс белого при студийном свете фиксируется вручную: 5600K.
- Исходники пишутся на карты CFexpress Type A объёмом 160 ГБ.
