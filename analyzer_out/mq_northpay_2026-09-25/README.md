## Почему патчи семантически неверны (проверено прогоном харнесса)

- `round(raw*100+0.5)/100` — модель путает с `floor(raw*100+0.5)`: `round(333.83)=334`,
  поэтому `test_refund_basic_third` (10.0/3 → 3.33) даёт 3.34. Воспроизведено
  прогоном фикстуры вне ядра: FAIL ровно на этом тесте, остальные 6 PASS.
- `Decimal(...)` — возвращает `Decimal`, не `float`: `Decimal('3.33') == 3.33` → False.
- `round(raw*100)/100` — banker's rounding: 0.125 → 0.12, ловится
  `test_refund_midpoint_half_up_not_bankers`.

## Воспроизводимость и главный вывод

- Seed 42: **байт-идентичный патч** вчера и сегодня (`round(raw*100)/100`).
- Seed 102: класс воспроизвёлся, патч другой (вчера Decimal, сегодня round+0.5).
- Seeds 100/101 вчера **completed** с корректным `int(raw*100+0.5)/100`, сегодня
  оба tests_failed (оба Decimal). → **исход определяется формулировкой payload,
  а не сидом.** Модель на temp 0 детерминирована относительно промпта; сид влияет
  на промпт лишь косвенно через план.

## Вердикт для Layer 2

Layer 1 не чинит» — **ВЫПОЛНЕНО**: класс воспроизводится, частота в данной
конфигурации 14/14 (совокупно с 2026-09-24: 16/18), патчи валидны формально и
применяются — их ловит только прогон реальных тестов, не shape-валидация.
